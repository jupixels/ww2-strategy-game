# CLAUDE.md — Iron Dominion 1936

Browser grand-strategy game of WWII (1936–1950) on two maps: the original Europe map (default) or the world map, chosen on the main menu. Static site, no build step, served by GitHub Pages from `main`. Single player, hot-seat, and online multiplayer (PeerJS). See `README.md` for the player-facing overview.

## Working with the owner
- Push finished, tested work **straight to `main`** (the owner asked for this; the live site updates from it). Ship in playable steps, never leave `main` broken.
- Fix bugs you come across and improve features as you go — the owner has given creative freedom, but propose large new directions before building them.
- **When you add or change a player-facing system, update the tutorial** (`js/ui/tutorial.js`), the field manual tips (`TIPS` in `js/ui/inbox.js`) and the README feature list.
- Audio must come from the owner's sound library **jupixels/game-sounds** (Kenney CC0) via its `sfx.js` — see "Sound" below. Don't synthesize new effects unless the library has nothing that fits, and say so.

## Run and test
```bash
python3 -m http.server 8765            # then open http://localhost:8765 (fetch/audio/multiplayer need a server)
node tests/sim.js 1936,1939,1941,1944 168 7   # AI-vs-AI campaigns: crashes, invariants, who wins
node tests/trace.js 1941 60 7 GER,SOV,ENG     # month-by-month national stats
node tests/play.js | tests/mp.js | tests/hot.js | tests/tutorial.js | tests/end.js | tests/audio.js   # Playwright, needs the server running
```
Playwright scripts use `/opt/npm-tools/node_modules/playwright` and Chromium at `/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`; elsewhere set `PW=<path to node_modules/playwright>` and they use its bundled browser. Env: `SC=1941 TAG=SOV MONTHS=4 node tests/play.js`, `OUT=<dir>` saves screenshots, `MOBILE=1 W=390 H=844` for phone layout. Before pushing, at minimum run `sim.js` and `play.js`, plus `mp.js` if you touched networking, `tutorial.js` if you touched the UI or tutorial, and `audio.js` if you touched sound. Missing-sound 404s are not errors; page errors are.

## Architecture
Classic `<script>` files sharing one global scope, loaded in the order listed in `index.html` (order matters — later files use earlier globals). No modules, no bundler.

- **Two maps.** `index.html` reads `MAPKIND` (`localStorage['idom-map']`, or `?map=world|europe`) and `document.write`s the map data and the renderer: Europe = `data/map-europe.js` + `js/ui/render-europe.js` (the original game's map and renderer, kept as they were plus a small shim at the end giving the shared UI `gridAt`/`nearX`/`wrapOffsets`/`animTo`/`setMapMode`/`miniSource`/`paintWorld`), world = `data/map.js` + `js/ui/render.js`. Switching maps reloads the page (`switchMap()` in `menu.js`). Core code tests `WORLD` (true when the map data has sea zones) and `REALM` ('Europe' / 'the world') for victory thresholds, wording, sea zones (`SEA`/`COAST_ZONES` literal on Europe) and Asia-only scenario steps. Nations whose capital isn't on the map become `off`/`hidden` at load (so on Europe the USA is the old offstage power and Japan etc. never appear), and are dropped from `MAJORS` and from the starting alliances. Saves: `iron-dominion-v4` (Europe) and `iron-dominion-v4-world`; `loadSaved` rejects a save whose province count doesn't match. Multiplayer: the host's lobby message carries `map`; a client on the other map reloads onto it and rejoins via `?join=`; invite links carry `&map=world`. Test both maps: `MAP=world` for `tests/load.js`-based scripts and the Playwright scripts (default is Europe).
- `data/map.js` — generated world map (`MAP`: 687 provinces, adjacency, province and sea-zone borders, coast/lake/river polylines, sea zones, RLE rasters for province ids (sea zones are ≤ −2) and biomes). Don't hand-edit: regenerate with `node tools/worldmap/build.js <dir of Natural Earth 50m GeoJSON> [preview.png]` (land, admin_0_countries, lakes, rivers_lake_centerlines, geography_regions_polys, glaciated_areas from github.com/nvkelso/natural-earth-vector `geojson/`). Projection: Miller cylindrical, 20 world units per degree of longitude, wrapping east–west at 169°W (`WW` is the circumference). The first `MAP.nlegacy` = 234 provinces are the Europe map (`data/map-europe.js`), resampled through its fitted conic projection (`oldproj.json`) so names, ids, events and scenarios are unchanged; everything else grows from the seed cities in `tools/worldmap/seeds.js` (owner, VP, factories, `c` colony, `b` island blob), along with sea zones, resources and strait links.
- `js/core/` — **the simulation. Must stay DOM-free** so it runs in Node (`tests/load.js` concatenates these files into a VM).
  - `util.js` seeded `rnd()` (state in `G.rs`), `Hooks` event bus, `notify()`/`sfx()`.
  - `data.js` all static catalogs: `NATDEF`, `UNIT`, `TECHS`, `FOCUS`, `CARDS`, `GENERALS`, `SEA`, `RESOURCES`, `ACH`, `SCENARIOS`, `MODES`.
  - `map.js` `PROV`/`ID`/sea zones/resources/weather flags (by latitude), `dist()` (wraps round the globe), `inEurope(tag)`. `state.js` `G`, accessors, unit-stack helpers, `newGame()`.
  - `economy.js` income, oil/steel (`oilBreakdown()`: half upkeep in peacetime; `fuelMul()` scales tanks/air/ships by how much of the upkeep income covers once the tanks are empty, floor 60%), building, research, focus. `military.js` sea control, **sea transport** (`convoyTargets()`/`shipConvoy()`/`landConvoys()`: armies in a port sail up to `convoyHops()` sea zones; `G.convoys` resolve in `endMonth()` after the naval battles, losing a share to enemy ships on the route; `sealift()` caps divisions shipped per month, `n.lift` counts them), fleets (`FLEET_MOVES` = 2 zones a month, `f.mv` counts moves), supply, air, generals, `battle()`, capture/capitulation, naval war. `diplomacy.js` war, factions, peace, pacts, inbox, the call to arms (`callToWar()`; AI allies decide in `aiAnswersCall()`, humans get a `calltowar` decision) and non-belligerent members (`G.nbm`: Japan joins the Axis without inheriting its wars until Pearl Harbor; `syncFaction()`/`allyWar()` also respect pacts such as the Soviet–Japanese neutrality pact). `systems.js` medals, visibility, cards, spies, home front, agendas, decisions. `events.js` historical events. `orders.js` **`doCommand(tag, cmd, mode)`** — the single entry point for every player action. `ai.js`, `scenario.js` (1939/41/44 starts replay history), `turn.js` `endMonth()` + victory.
- `js/ui/` — `render.js` (world map: seven zoom levels of 512-px tiles cached in `TILES`; terrain raster `polCv` painted once; provinces are vector shapes `PPATH` linked from the shared boundary chains in `MAP.borders` (side −1 = sea), indexed per ring in `PROV_B`; nation fills, occupation stripes, fog and weather are painted per province into tiles; captures invalidate only that province's tiles; vector layers cut into 300-unit buckets; selection/map-mode overlays are vector fills (`OVL`) clipped to land; counters are cached sprites; `nearX`/`w2s` handle the wrap), `render-europe.js` (the original Europe renderer), `icons.js` (SVG icons + flags), `fx.js` (VFX + frame loop), `sound.js`, `hud.js` (top bar, dossier, cards, selection, tooltips), `panels.js` (8 drawer tabs), `inbox.js` (newspapers/decisions, reports, end screen, timelapse, help), `input.js`, `tutorial.js`, `menu.js` (menus, setup, lobby), `main.js` (**`Ctl` controller**, save/load, boot).
- `manifest.webmanifest` + `sw.js` + `icons/` — installable app. `sw.js` is network-first (cache only when offline), skips range requests (streamed music) and anything off-site except the font/CDN hosts, so PeerJS is untouched.
- `js/net/net.js` — multiplayer. `js/net/leaderboard.js` — online leaderboard. `js/vendor/` — `peerjs.min.js`, `sfx.js` (third-party; don't edit).

### Core rules (break these and multiplayer, saves or tests break)
1. **All state lives in `G` and must be plain JSON** (it is saved to localStorage and sent over the network). No functions, Sets, or class instances in `G` (`G.warSet` is rebuilt by `rebuildWarSet()` and stripped by `serial()`). Events in the inbox are referenced by id, not by object.
2. **Every player action goes through `Ctl.act({c:...})` → `doCommand()`**. Add new actions as a `case` in `doCommand` with validation, never by mutating `G` from UI code. The UI calls `Ctl.act`; the host runs client commands through the same function.
3. **Core code uses `rnd()`, UI code uses `Math.random()`** (keeps games reproducible from `G.seed`; the weekly challenge and leaderboard replays depend on it). **Never call `rnd()` inside an `Array.sort` comparator** (or anything else whose call count is engine-specific): browsers and Node sort with different comparison counts, so the dice drift and server replays fail. Score first, then sort.
4. **Core never touches the DOM.** It reports with `Hooks.emit(...)`/`notify(to, …)`/`sfx(name, to)`. `to` is a nation tag or `'*'`; the UI shows it only if `to === ME`. The MP host forwards selected hooks to clients (`Hooks.on('*')` in `net.js`).
5. Humans: `G.humans[tag] = {name, dead?, away?}`. Use `isHuman()`, `liveHuman()` (not dead, not away — away players are run by the AI). `ME` is the nation this screen shows (`null` = spectator). Never assume a single player.
6. Save format is versioned (`G.v = 4`, key `iron-dominion-v4`). If you change `G`'s shape incompatibly, bump the version or migrate in `adopt()`.

### Controller modes (`Ctl.mode`)
`sp` single player · `hot` hot-seat (sequential, `G.hs` = whose turn, pass screen hides the map) · `host` / `client` online (simultaneous: attacks are **queued** as `G.orders` and resolved in `resolveOrders()` at month end; armies ordered into each other fight a meeting engagement) · `watch` spectator. `Ctl.canAct()` gates input.

### Multiplayer protocol (`net.js`)
Host-authoritative. Transports: `'p2p'` (PeerJS, room id `iron-dominion-v4-<CODE>`) and `'local'` (BroadcastChannel between tabs — use this for tests). Client→host: `hello{name,token}`, `pick`, `cmd`, `ready`, `chat`, `hb`. Host→client: `welcome`, `lobby`, `state` (gzipped `G` + queued effects `ev`), `toast`, `chat`, `hb`. Heartbeats every 3 s; silent players are marked away after 12 s and the AI takes over; rejoining with the same `localStorage` token reclaims the nation. Host drop pauses the game (no host migration yet). Real internet play through the PeerJS cloud server has **not** been verified from the dev sandbox.

## How to add things
- **Unit type:** `UNIT` + `LAND`/`AIR`/`NAVY` in `data.js`, strength in `unitStrength()` (`military.js`), icon in `icons.js`, counter/dossier display, AI build mix in `aiBuild()`.
- **Tech / focus / card / spy op / decision / achievement:** add to its catalog in `data.js` (or `SPY_OPS` in `systems.js`), then its effect in `grantTech`-consumers / `completeFocus()` / `playCard()` / `spyOp()` / `enactDecision()`, and teach the AI to use it (`ai.js`).
- **Historical event:** append to `EVENTS` in `events.js` (`actor`, optional `tgt` + `topts`, `cond`, `opts[{t,e,f(chooser)}]`). Option functions must only mutate `G` through core helpers. If it predates a later start date, `applyScenario()` marks it done automatically.
- **Nation:** `NATDEF` needs `mp` (manpower — a past bug left every nation at 10k), `stab`, `u`, `flag`, `cap`; its provinces come from the map data (`seeds.js` for anything outside Europe; rebuild the map). Flag types live in `paintFlag` (`icons.js`).
- **Province outside Europe:** add a seed line to `tools/worldmap/seeds.js` and rebuild; new straits go in `LAND_LINKS`/`SEA_LINKS`. Colonies (`c`) give little manpower and start with a token garrison.

## Systems added in the November 2026 revamp
- **Expeditionary forces** (`state.js`): `p.g = {TAG:{u,r,xp,dig}}` are armies standing in an ally's province. Use `stackOf(pid, t)` (own stack or guest stack) instead of `G.prov[pid]` whenever a nation's army is meant; `forcesAt(p)` counts host + guests for defence; `depositAt()` puts troops down; `sanitizeGuests()` (in `resetReady`) sends guests home when the alliance ends; `armiesOf(t)` lists every province with an army of t. `battle()` srcs may carry `o` (the attacker tag) — always pass it for guest stacks.
- **Fronts** (`js/core/fronts.js`): `n.fronts = [{id,name,z,o,gid,pull,last}]`; `runFronts()` runs in `endMonth()` after `resolveOrders()` for live humans, using only units still ready. Commands go through `doCommand({c:'front', op})`. UI: Command → Fronts (`frontsPanel` in panels.js), map lines `drawFrontLines`/`drawFrontLabels` (hud.js, called from both renderers), dossier `frontChip`.
- **Drawers**: six rail tabs; `SUBS`/`subTab` in panels.js give Command (fronts/armies/generals/convoys), Plans (focus/tech/nation) and Ledger (ledger/dec) their sub-pages; `openTab('focus'|'tech'|'dec'|'generals'|'fronts'|'nation'…)` aliases still work.
- **Situation report** (`systems.js` `situationReport()`/`tickReports()`): inbox item `type:'report'` every January and July; shown by `showReport()` in inbox.js; never blocks a multiplayer turn.
- **National systems** (`js/core/nations.js`): `SIGS`, `n.sig`, `sigTick()` monthly, `aiSignature()` for the AI, `doCommand({c:'sig', op})`; effects hook into `income()` (`sigIncomeMul/Add`), `tickHomeFront` (`sigStabMod`), `oilBreakdown`/`fleetPower` (`anchored`), `defenseValue` (Union sacrée), `checkCapitulation` (`frenchExile`).
- **Second act** (`js/core/acts.js`): `checkSecondAct()` each month; `G.act = {k, doom, …}` with k in `ACTS` (coldwar, reich, redtide, american, exhaust); the game then ends at `ACT_END` (1955) via `actEndTurn()`. Peace conference (`kind:'conference'` decision), Doomsday Clock, `doCommand({c:'sphere'})`, decolonisation, armistice conferences, World War Three at midnight. AI wars after the war stay off bloc members.
- **Formables**: `DECISIONS` may have `absorb:[tags]`; forming turns claimed provinces into cores and annexes allied minors of the union; decisions whose cities are missing from the map are dropped in `map.js`. The AI forms them in `aiTurn`.
- **Leaderboard** (`js/net/leaderboard.js`, `leaderboard-config.js`, `firestore.rules`, `firestore.indexes.json`, `functions/`): Firestore REST, no SDK, no login; off until `LEADERBOARD_CONFIG` is filled. Clients write only to `submissions` (gzipped `G.rec`); the `verifyScore` Cloud Function replays it (`functions/verify.js`) and publishes to `scores`. Boards: all / world / europe / week / per nation; scores are rated (`ratedScore()` in `replay.js`: difficulty × start date × nation stars).
- **Recording & replay** (`js/core/replay.js`): single-player games record `G.rec = {o:start opts, c:[[turn, tag, cmd]…]}` in `doCommand`; `replayGame(rec, turn)` rebuilds the game. So **anything that changes `G` for a human outside `doCommand` must call `recBad(why)`** (it disqualifies the record), and the intro newspaper goes through `introNews()`. After changing `js/core/` or `data/`, run `node functions/sync.js` (new `GAME_BUILD` in `js/core/build.js` + an archived copy in `functions/builds/`, last 12 kept) and commit both; the owner redeploys functions. `tests/replay.js` (headless, incl. save/reload) and `tests/verify.js` (tamper cases, `MAP=world` too) cover it.
- **Watch & pace**: the verifier also returns a `film` (every month's owners from `G.hist`, the tags list, and `pace[turn]` = rated score at the start of each month via `replayGame(rec, end, onMonth)`); `functions/index.js` stores it gzipped in `replays/{id}` (`data` string). Client: `lbFilm()`, `lbWatch()` (switches map via `?watch=<id>`), `playFilm()` in inbox.js (also behind the end-of-war timelapse), `lbFetchPace()`/`paceInfo()` for the top bar's **You / #1** stat (`#sPaceW`, weekly only), `lbLastWeekNews()` once per new week (`profile().seenWeek`, `profile().posted[week]`).
- **Save slots & undo** (`js/ui/saves.js`, UI only): single-player campaigns carry `G.slot`; `Ctl.save()` → `saveSlot()` writes the live game raw to `SAVE_KEY` (sync) plus a gzipped copy in `SAVE_KEY-slot-<id>` and a line in `SAVE_KEY-slots` (max 12). Hot-seat/online/tutorial keep their old keys. `Undo` keeps 6 month-start snapshots in memory; undoing calls `recBad('undo')` (asks first). Commands other than reading news count as "moves this month" (`Undo.acts`). Test: `tests/saves.js`.
- **Weekly challenge**: `weeklySpec(key)` (`'YYYY-Www'`) is a pure schedule from `WEEKLY_EPOCH`, re-rolled so a nation never repeats within four weeks; `weeklyNext()` lists the upcoming ones. Changing `WEEKLY_POOL`/`weeklyRoll` reshuffles every future week and breaks verification of the current one — append, don't reorder, and only between weeks.
- Tests: `tests/convoy.js`, `tests/replay.js`, `tests/verify.js` (headless), `tests/fronts.js`, `tests/navy.js`, `tests/leaderboard.js` (Playwright; mocks Firestore and runs the real verifier; also covers Watch, the pace stat and last week's results), `tests/saves.js` (Playwright).

## Balance notes
Sea war: `targetsFor()` returns 'naval'/'land' for instant one-zone hops and 'convoy'/'invade' for convoys. The AI ships convoys in `aiConvoys()`; Western Allied landings on a major's European coast wait until late 1942 and need 2.8:1 odds. China never capitulates while it holds land and gets "Trading space for time" against Japan; AI armies never strip their capital. `tests/convoy.js` (headless, both maps) and `tests/navy.js` (Playwright, world map) cover convoys, fleets, oil and the call to arms.
World map additions: the Commonwealth (CAN, AST, NZL, SAF, RAJ) starts in the Allies, Mongolia in the Comintern, Japan and Manchukuo in their own `SPHERE` faction until the Tripartite Pact. Minors only join an alliance that is already fighting all their enemies (stops chain-reaction world wars). Japan and the USA are `SEA_POWERS` in `ai.js`: idle armies march to ports facing the enemy and land often. Pacific outcomes vary a lot by seed; Japan usually expands in China and falls around 1945, sometimes earlier.
Tune with `tests/sim.js` / `trace.js` across several seeds. Current shape (seeds 3, 7): from 1936/1939 the Axis usually falls by ~1945; from 1941 the Eastern Front swings back and forth (graded supply, "Not one step back", General Winter, Siberian divisions); occasional Axis wins are fine. Key levers: loss rates in `battle()`, `supLevel()`, `OIL_BASE`, scenario `bolster()` numbers, AI `aggression`, partisan rates in `tickResistance()`.

## UI notes
- Look: dark "situation room" palette in `css/game.css` (original) + `css/revamp.css` (additions). Fonts: Big Shoulders Stencil (display), Barlow Semi Condensed (body), Cormorant SC (map), Special Elite (newspaper).
- Performance: static map layer is cached; only redraw it when `staticDirty`. Camera shake offsets the composite, never forces a static redraw. Use the cached glow/puff sprites in `fx.js`, keep particles under `MAX_PARTS`, and keep 60 fps during big battles (check with the frame timer in `tests/play.js`).
- Modals: close them with `closeModal()` — it also releases the newspaper queue (`flushInbox`), which otherwise stalls.
- Phone layout (≤820 px) is a supported target: rail moves to the bottom, resource labels hide, the card hand hides while a sheet is open. Check `MOBILE=1` screenshots after UI changes.

## Sound
Exception to the rule below: the user asked for new sounds to come from the ElevenLabs MCP. The map-mode sound in `assets/sounds/map/` was generated that way. The owner does **not** want background ambience (sea/wind loops were tried and removed); keep the original music only.

`js/ui/sound.js` wraps `window.SFX` from `js/vendor/sfx.js` (copied unchanged from jupixels/game-sounds `lib/sfx.js`). Library files used live in `assets/sounds/<category>/` (copy only the MP3s you use, using `sounds.json` volumes as a guide); the original set is `assets/sfx/`. Library: `git clone --depth 1 https://github.com/jupixels/game-sounds` — read its `CATALOG.md` "Quick picks" first. War sounds (gunfire, rifles, MG, artillery, howitzer, siren, warplane, tank, ship horn, morse radio) are real recordings from the library's `ww2/` family in `assets/sounds/ww2/`; music is its `music/` family in `assets/music/`, **streamed** through `<audio>` elements into the music bus (decoding minutes of audio would cost tens of MB), alternating the two tracks. Nothing is synthesized any more. Some ww2 recordings are CC-BY: anything you add from that family must get a credit line in the README (each entry in the library's `sounds.json` has `license`, `author`, `source_url`). Kenney sounds need only the general Kenney.nl credit. To re-cut a clip, edit `CLIPS` in the library's `tools/build/add_recorded.py` and re-copy the MP3.
